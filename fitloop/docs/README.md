# FitLoop Architecture & Contracts

System documentation for the FitLoop platform across frontend, backend, and machine learning components.

## Documents
- `architecture.md`: Overall platform topology, multi-model execution graph, and data flow.
- `api-contracts.md`: Interface contracts between Backend API, Model 1 (Measurement), and Models 2/3 (Garment Sizing).
- `measurement-definitions.md`: Standardized anthropometric measurement specifications (ISO 7250 / ISO 8559).
