1. COMPONENT ARCHITECTURE & DESIGN
--------------------------------------------------------------------------------
A. GarmentEmbeddingExtractor:
   - Backbone: torchvision.models.mobilenet_v3_small(weights=MobileNet_V3_Small_Weights.DEFAULT)
   - Feature Head: classifier replaced with torch.nn.Identity(), yielding 576-dim feature vectors.
   - Normalization: Strict L2 unit normalization (norm == 1.0) on CPU in eval() mode with torch.no_grad().
   - Cosine Similarity: compute_cosine_similarity(emb1, emb2) returning float bounded strictly in [0.0, 1.0].

B. Database Persistence (ItemEmbedding):
   - Table: item_embeddings
   - Columns:
     * id: Integer PK autoincrement
     * item_id: Integer FK (wardrobe_items.id, ondelete="CASCADE"), unique=True, index=True
     * embedding_json: Text (serialized 576-dim float list)
     * model_version: String(100), default="mobilenet_v3_small"
     * created_at: DateTime(timezone=True) UTC
   - Relationships:
     * WardrobeItem.embedding_record (1-to-1 relationship, cascade="all, delete-orphan")
     * WardrobeItem.to_detector_dict() deserializes embedding_record and exposes "embedding"
     * WardrobeRepository.get_user_wardrobe() utilizes selectinload(WardrobeItem.embedding_record)
       for eager loading without detached instance errors or N+1 queries.

C. DuplicateDetector Visual Similarity Blending:
   - Dynamic weight rebalancing when both candidate and inventory item possess embeddings:
     * Base: category 0.40, dominant_color 0.30, visual_similarity 0.30 (Sum = 1.00)
     * With secondary: category 0.35, dominant_color 0.25, visual_similarity 0.25, secondary_color 0.15 (Sum = 1.00)
     * With pattern: category 0.40, dominant_color 0.25, visual_similarity 0.30, pattern 0.05 (Sum = 1.00)
     * With sec + pat: category 0.35, dominant_color 0.25, visual_similarity 0.25, secondary_color 0.10, pattern 0.05 (Sum = 1.00)
   - Graceful fallback: when either item lacks embedding, uses previous text/color weights (100% backward compatible).
   - Cross-category rule: when cat_sim == 0.0, score is strictly bounded:
     composite_score = round(float(np.clip(0.20 * dom_sim + 0.10 * vis_sim, 0.0, 1.0)), 3)
     ensuring cross-category pairs remain far below the UNIQUE ceiling (< 0.65).
   - Result payload includes visual_similarity in breakdown dict.

D. FastAPI Service Wiring:
   - Singleton GarmentEmbeddingExtractor(device="cpu") initialized on app startup.
   - POST /api/v1/scans: extracts 576-dim embedding for each detected garment bounding box
     and persists into item_embeddings table via repo.add_scan_and_items().
   - POST /api/v1/check-before-buy: extracts candidate embedding and executes multi-attribute
     similarity matching against user inventory with visual cosine blending.
